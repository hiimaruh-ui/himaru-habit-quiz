# 我慢しない！私に合うダイエットの続け方診断

ひいまるの無料プレゼント。HTML・CSS・JavaScriptだけで動く、生活習慣の振り返りツールです。医学的診断ではありません。

## 文章・画像を変更する場所
- `data.js`：質問、配点、タイプの説明、おすすめ習慣、共通メッセージ。
- `app.js`：トップ画面などの文章、画面の動き、PNGカードの作成。
- `style.css`：色、余白、文字サイズ。
- `A.svg`〜`F.svg`：6種類のモチーフ。人物は使用していません。
- `config.js`：公式LINEのURL。未設定ではリンクボタンを表示しません。
- `logic.js`：配点・同点判定。

## 公式LINEのリンクを設定する
`config.js` の `lineUrl: ""` の引用符の間に、ご自身の公式LINEのHTTPS URLを入れて保存します。line.me・lin.ee・liff.line.meに対応しています。公開サイトにも変更ファイルをアップロードしてください。URL未定の今も、結果文のコピーと画像保存を使えます。

## 公開の更新
GitHubの専用リポジトリ `himaru-habit-quiz` に変更ファイルをアップロードしてコミットします。Pagesはmainブランチのルートを使用します。変更前のファイルを保管し、反映後に公開URLで確認してください。既存の別診断リポジトリは変更しません。

## 判定
2026-10-29にセミナー用へ改訂。A=お疲れ、B=自分後回し、C=完璧主義、D=めんどくさがり、E=我慢しすぎ、F=三日坊主の6タイプです。各タイプ2問を主項目（+2）とし、関連する項目を+1にしています。配点はこの改訂時の編集用設計で、医学的に検証された尺度ではありません。全員が最後の13問目に回答します。6タイプに対応する行動の文章から1つを選び、タイプ名は表示しません。12問の配点は維持し、13問目では加点しません。最高点が単独ならそのタイプ、同点なら13問目で選んだタイプが最高点の候補に含まれる場合だけ決め手にします。候補に含まれなければ、同点候補から本人が選ぶ画面へ進みます。特定のタイプを固定で優先しません。補足は0点とメインを除外し、同点の補足は併記します。
「どれも難しい」の追加候補は、今回のために作成した小さな行動の提案です。

## 保存と個人情報
カードは1080×1920のPNG。ブラウザ内で作成します。回答や個人情報をサーバーへ送る機能、広告、アクセス解析はありません。ページ再読込では最初からになります。
iPhoneでは画像共有・長押し保存を使用できますが、実機やアプリ内ブラウザにより操作が異なります。保存できない場合はSafariまたはChromeで開いてください。

## テスト
Node.jsがある環境では `node test.cjs` で配点を検証できます。6タイプ・4,095通りの選択×最後の6回答（24,570通り）・同点と補足の条件を検証します。文章や配点を変えたら、画面と保存画像も確認してください。
